# Buenas Prácticas

## Seguridad

- No guardar contraseñas reales en GitHub.
- Usar credenciales de laboratorio o variables de entorno.
- Proteger la rama principal del repositorio.
- Revisar los comandos antes de ejecutarlos en los dispositivos.
- Evitar publicar direcciones IP públicas o datos sensibles.

## Organización

- Separar los scripts por fabricante.
- Mantener la documentación actualizada.
- Usar nombres claros para archivos y carpetas.
- Guardar evidencias del funcionamiento del proyecto.
- Mantener un inventario ordenado de los dispositivos.

## Versionamiento

- Crear commits descriptivos.
- Usar ramas de trabajo por fabricante.
- No aplicar cambios directamente en producción.
- Validar primero en un entorno de laboratorio.
- Documentar cada cambio importante.

## Automatización

- Usar scripts reutilizables.
- Validar conectividad antes de ejecutar configuraciones.
- Registrar errores durante la ejecución.
- Separar inventario, lógica y configuración.
