# Flujo de Trabajo

El proyecto utiliza un flujo de trabajo basado en buenas prácticas de control de versiones, documentación y automatización de red.

## 1. Crear Cambios

El administrador modifica los scripts o documentación de forma local, usando un editor como Visual Studio Code.

## 2. Validar Cambios

Antes de subir los cambios al repositorio, se revisa que los comandos sean correctos y que la estructura del proyecto esté organizada.

## 3. Crear Commit

Cada cambio debe registrarse con un mensaje claro y descriptivo.

```bash
git add .
git commit -m "Actualización de configuración base Fortinet"
